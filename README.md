# Потолок Профи — сайт с калькулятором и заявками в Telegram и ВК

Готовый продукт для компаний по натяжным потолкам:

- **Продающий лендинг**: первый экран, карточки услуг, «Почему мы», этапы работы, вопросы, контакты и соцсети (ВК, Telegram, Instagram, WhatsApp).
- **Калькулятор в 5 шагов** с расшифровкой цены. Кнопка «Рассчитать» на карточке услуги сама подставляет услугу в калькулятор.
- **Заявки автоматически уходят** в Telegram (бот → канал, группа или личка) и во ВКонтакте (сообщество → администраторам). Каждая заявка дублируется в файл на сервере.
- **Админка с паролем**: заявки, услуги (название, картинка, описание, цена), цены, тексты, соцсети, токены ботов, тестовая отправка, смена пароля.
- **Без базы данных**: всё хранится в JSON-файлах в папке `data/`, которая не отдаётся наружу.

> ⚠ **Демо-данные**: бренд «Потолок Профи», город «Казань», контакты, все цены и тексты «Почему мы» условные. Перед запуском для клиента замените их в админке.

Стек: React + TypeScript + Vite (сайт), Node.js без внешних зависимостей (сервер).

## Быстрый старт (на своём компьютере)

Нужен **Node.js 22.18 или новее** (рекомендуется 24 LTS, скачать на nodejs.org).

```bash
npm install
npm run set-password     # придумайте пароль админки (от 8 символов)
npm run dev              # сайт: http://localhost:5173   админка: http://localhost:5173/#/admin
```

`npm run dev` запускает сразу и сервер, и сайт с автообновлением.

Проверка перед публикацией:

```bash
npm test                 # тесты расчёта, заявки и проверок (29 шт.)
npm run build            # проверка типов и сборка сайта в dist/
npm start                # рабочий режим: http://localhost:3000
```

## Что где менять

Почти всё меняется в **админке** (`/#/admin`), программист не нужен.

| Вкладка | Что там |
|---|---|
| Заявки | Все заявки с сайта и статус доставки: «TG: доставлено», «ВК: ошибка» и т. п. |
| Услуги | Карточки: картинка (загрузка файла), название, описание, подпись цены, что подставить в калькулятор, порядок, показ/скрытие |
| Цены | Модель цены (монтаж включён или отдельно), минимальный заказ, разброс ±, полотна, доп. работы, коэффициенты |
| Тексты | Заголовки, «Почему мы», этапы, вопросы, условия замера, сообщение после заявки, политика конфиденциальности |
| Компания и соцсети | Название, город, телефон, логотип, фото, ссылки ВК, Telegram, Instagram, WhatsApp, плашка «Демо» |
| Telegram и ВК | Токены ботов, куда слать заявки, кнопка «Отправить тестовую заявку» |
| Пароль | Смена пароля |

Сохранённые изменения сразу видны на сайте, пересобирать ничего не нужно.

Начальные (демо) значения лежат в `src/config/defaults.ts`. При первом запуске они копируются в `data/settings.json`.

## Подключение Telegram и ВКонтакте

Подробные шаги есть в админке, вкладка «Telegram и ВК» → «Как подключить». Коротко:

**Telegram:**
1. В @BotFather выполните `/newbot` и получите токен.
2. Создайте канал или группу для заявок и добавьте туда бота администратором.
3. В админке укажите токен и chat id: `@имя_канала` или `-100…` для закрытого канала. Несколько адресов пишутся через запятую.

**ВКонтакте:**
1. В сообществе включите «Сообщения сообщества».
2. Создайте ключ доступа с правом «Сообщения сообщества».
3. Каждый получатель должен один раз написать сообществу.
4. В админке укажите ключ и id получателей через запятую. Для беседы используйте 2000000000 + номер беседы.

Нажмите **«Отправить тестовую заявку»**: если что-то не так, админка покажет понятную причину, например «Бот не может писать в этот чат: добавьте его администратором».

**Как работает отправка.** Сайт отправляет заявку на свой сервер. Сервер **сам пересчитывает цену** по тарифам (браузеру не доверяет), сохраняет заявку в `data/leads.jsonl` и рассылает её в Telegram и ВК. Токены хранятся только на сервере и в браузер не попадают. Если ни один канал не ответил, клиент видит честное сообщение «Заявка сохранена, но уведомление не дошло» и кнопки, чтобы продублировать её вручную.

## Публикация в интернете

Нужен хостинг с **Node.js**: любой VPS (Timeweb Cloud, Selectel, REG.RU, Beget VPS и т. п.) или облако с поддержкой Node.js. Обычный «статический» хостинг не подойдёт: заявки отправляет сервер.

На сервере (Ubuntu):

```bash
# 1. Node.js 24
curl -fsSL https://deb.nodesource.com/setup_24.x | sudo -E bash - && sudo apt install -y nodejs
# 2. Проект
git clone <ваш-репозиторий> potolok && cd potolok      # или загрузите архив
npm ci && npm run build
npm run set-password
# 3. Автозапуск (pm2)
sudo npm i -g pm2
PORT=3000 TRUST_PROXY=1 pm2 start "npm start" --name potolok && pm2 save && pm2 startup
```

Перед Node поставьте **nginx с HTTPS** (бесплатный сертификат Let's Encrypt через `certbot --nginx`):

```nginx
server {
  server_name potolok-example.ru;
  client_max_body_size 10m;
  location / {
    proxy_pass http://127.0.0.1:3000;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-For $remote_addr;
    proxy_set_header X-Forwarded-Proto $scheme;
  }
}
```

Переменные окружения:

| Переменная | Зачем |
|---|---|
| `PORT` | Порт сервера (по умолчанию 3000) |
| `TRUST_PROXY=1` | Сервер стоит за nginx: брать IP и https из заголовков |
| `DATA_DIR` | Папка с данными (по умолчанию `./data`) |
| `ADMIN_PASSWORD` | Пароль при самом первом запуске, вместо `set-password` |
| `TELEGRAM_API_BASE`, `VK_API_BASE` | Другой адрес API, например прокси |

**Резервная копия:** регулярно копируйте папку `data/` — в ней настройки, заявки, пароль (в виде хэша) и загруженные картинки.

## Безопасность

- Пароль хранится только в виде хэша (scrypt) в `data/auth.json`. Вход ограничен: 8 попыток за 15 минут. Сессия хранится в cookie с флагами HttpOnly и SameSite=Strict и действует 12 часов.
- Запросы с чужих сайтов отклоняются (проверяются Origin и JSON). Действует ограничение: 5 заявок с одного IP за 10 минут. Есть скрытое поле-ловушка для ботов.
- Загружаются только JPG, PNG и WebP до 5 МБ; тип проверяется по содержимому файла.
- Заголовки безопасности: CSP, X-Frame-Options, nosniff. Шрифты отдаются со своего сервера, без Google.
- Сайт собирает персональные данные: заполните текст политики во вкладке «Тексты» (сейчас там шаблон). Галочка согласия в форме обязательна.
