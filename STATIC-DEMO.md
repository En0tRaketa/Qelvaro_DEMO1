# Статическое демо «Потолок Профи»

## Публикация на Vercel
1. Распакуйте архив и откройте папку проекта.
2. Выполните `npm install` (нужен Node.js 22.18+).
3. Выполните `npm run build`.
4. Загрузите папку `dist` в Vercel как статический сайт или подключите репозиторий. Build command: `npm run build`, Output Directory: `dist`.

## Две страницы
- `index.html` — лендинг.
- `admin.html` — демо-админка.

Админка: пароль по умолчанию `demo12345`. Можно менять настройки и сохранять их, но они сохраняются только в localStorage браузера, в котором открыто демо. Поэтому это демонстрация интерфейса, а не общая админка для всех посетителей. Очистка данных сайта сбрасывает настройки и пароль к демо-значениям.

Заявки остаются только в браузере; Telegram и VK не отправляют сообщения. Поля токенов мессенджеров и загрузка изображений предназначены только для демонстрации. Не вводите реальные пароли, токены или персональные данные.

Исходный дизайн, React-компоненты и стили сохранены. API заменён локальным демо-слоем, чтобы обе страницы работали на статическом хостинге без сервера.
